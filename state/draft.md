# 고려대병원 건립, 화성시 고시에 없는 이유

## 3초 요약
동탄에 700병상 규모 상급종합병원을 짓는 **고려대병원 건립** 사업이 2026년 3월 화성시·LH·고려대의료원 협약으로 공식화됐지만, 정작 화성시 고시·공고 목록에서는 이 사업이 조회되지 않는다.
사업장을 동탄에 알아보며 지역 개발 흐름을 직접 챙겨온 사업주라면, 이 소식이 왜 고시 목록만 봐서는 놓치기 쉬운지 짚어볼 만하다.

## 지금까지의 흐름

| 시점 | 내용 |
|---|---|
| 2025년 이전 | 동탄2신도시 의료시설·도시지원시설용지 매각공모 추진, 의료시설용지 매각공모는 3차례 유찰됐다 |
| 2025년 11월경 | '대규모 종합병원 포함 패키지형 등 개발사업' 공모 우선협상대상자로 고려대의료원 컨소시엄이 선정됐다 |
| 2026년 3월 18일 | 화성특례시가 동탄구청 대회의실에서 LH, 고려대학교 의료원, 컨소시엄 대표사와 업무 협약을 체결했다 |
| 2026년 3월 30일 | 고려대의료원 기자간담회에서 안암·구로·안산병원에 이은 '동탄 제4 고려대병원'이 2035년 700병상 규모 최상급 종합병원으로 문을 열 예정이라고 밝힘 |

## 이번에 새로 알려진 것

**고려대병원 건립**의 핵심은 세 가지로 정리된다.

1. **3월 18일 6자 협약으로 사업이 공식 출발선에 섰다.**
고려대의료원은 3월 18일 화성시 동탄구청에서 화성시, 한국토지주택공사(LH), 우미건설, 미래에셋증권, 리즈인터내셔날과 '고려대 동탄병원' 건립을 위한 6자 업무협약을 체결했다. 병원은 26개 진료과목, 700병상 규모로 조성될 계획이다.

2. **이 사업은 화성시 자체 고시·공고 대상이 아니다.** 사업 부지인 의료시설용지·도시지원시설용지는 LH가 매각·공급을 주관하는 택지이고, 건축 인허가 역시 사업 주체인 고려대의료원 컨소시엄과 해당 절차를 밟는 구조다. 그래서 동탄 개발 이슈를 화성시 고시 목록으로만 추적하면 이 사업의 진행 여부가 보이지 않는다. 실제 진행 상황은 LH 공고나 고려대의료원의 보도자료, 지역 언론 보도로 확인해야 한다.

3. **부지 좌표는 확인되지만, 착공을 의미하지는 않는다.** 부지는 Plus Code 54P2+JC7 일대로 확인되나(개념도 참고, 실제 축척과 다름), 고려대의료원은 2031년까지 설계와 인허가를 마무리하고 착공에 들어가 2035년 완공 및 개원을 목표로 사업을 추진할 계획이라고 밝혔다. 즉 2035년은 아직 계획 단계의 목표치이지, 확정된 준공일이 아니다.

## 정해진 것과 아직 아닌 것

| 구분 | 내용 |
|---|---|
| 확정된 것 | 3월 18일 6자 업무협약 체결, 700병상·26개 진료과목 규모 설정, 부지 좌표(Plus Code 54P2+JC7) |
| 계획 단계 | 2031년 착공 목표, 2035년 개원 목표, 경기도 사전 심의를 거쳐 설립 승인을 받은 상태 |
| 아직 안 정해진 것 | 실시설계 착수 시점, 착공 신고일, 최종 사업비 규모 |

화성시 고시 목록에 뜨지 않는 사업이라는 점은 이미 짚었으니, 진행 상황을 확인하려면 LH 공고와 고려대의료원 발표를 함께 봐야 한다는 점만 기억해두면 된다.

## 이 변화가 닿는 곳

700병상 상급종합병원이 들어서면 동탄2신도시 권역은 의료·바이오 연관 업종의 사무공간 수요가 생기는 구조로 바뀐다. 고려대의료원 관계자는 "화성은 발전 가능성이 높지만 현재 종합병원은 4곳이 전부고 상급종합병원은 한 곳도 없다"고 설명했는데, 이는 역으로 병원 개원 이후 의료기기·제약 영업, 임상시험수탁(CRO), 헬스케어 스타트업 같은 업종이 인근 지식산업센터를 사무실로 찾을 유인이 커진다는 뜻이다. 고려대의료원이 경기도 화성시 동탄에 1조원 규모를 투입해 700병상급 최상급 종합병원 설립에 나서는 것도 단순 진료시설이 아니라 '미래형 의료복합 플랫폼' 구현이 핵심 목표라는 점과 맞물린다. 다만 이 수요는 2035년 개원 이후부터 본격화되는 흐름이라, 지금 당장 체감되는 변화는 아니다.

## 앞으로의 일정

- 2031년까지: 설계·인허가 완료 목표(고려대의료원 발표 기준, 확정 착공일 아님)
- 2035년: 700병상 개원 목표(계획 단계 목표치)
- 실시설계 착수 시점, 착공 시점: <mark>미확정, LH·고려대의료원 추가 공고 확인 필요</mark>

## 이 주제를 고른 이유

동탄 사업장을 알아보는 과정에서 화성시 고시 목록만 들여다보고 "별다른 움직임이 없다"고 판단하기 쉬운 사례라서 골랐다. 고려대병원 건립처럼 LH 소관으로 분류된 굵직한 사업은 다른 창구를 봐야 보인다는 점을 공유하고 싶었다.
