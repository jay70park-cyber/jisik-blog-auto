## 왜 CSV 가 아니라 여기인가

`data/local_agenda.csv` 는 **봇의 작업 공간**이다.
`collect_hscity.update_agenda()` 가 새 고시로 현안을 갱신할 때
`단계`·`최근진전일`·`진전내용`·`확인필요` 네 칸을 통째로 덮어쓴다.
거기 적어둔 메모는 다음 갱신에 사라진다 (2026-11-02 확인).

**확인할 것, 틀리기 쉬운 것, 근거와 등급은 여기 적는다.**

## 근거 등급

| 등급 | 무엇 | 글에 쓸 수 있나 |
| --- | --- | --- |
| A | 회의록 원문, 시청 고시·보도자료, 법령 | 그대로 |
| A– | 우리 요약기가 만든 회의록 요약 | 쓰되 수치는 원문으로 확인 |
| B | 언론 보도 | 그대로, 출처 표기 |
| C | 개인 블로그·카페 | **쓰지 않는다.** 확인할 단서로만 |

2026-10-05 에 블로그를 근거로 취득세율을 써서 15%포인트가 틀렸다.
2026-10-08 에 유찰의 시제를 뒤집어 독자 문의가 들어왔다.
**등급을 적는 습관이 그 두 사고에서 나왔다.**

## 쓰는 법

- 새 사실이 들어오면 **출처와 등급을 함께** 적는다
- 자료끼리 어긋나면 **어긋난다고 적는다.** 한쪽을 지우지 않는다
- 확인 못 한 것은 **미결**에 남긴다. 본문에 단정하지 않는다
- 날짜가 바뀌는 값(최근진전일 등)은 CSV 가 맡는다. 여기엔 **왜 그런지**를 적는다
